2. Screen-by-Screen Engineering Redlines (Behavior & Edge Cases)

SCR-01: Command Center Redlines
  • Auto-Layout: Fixed 240px sidebar + 1fr fluid data table. Max container width 1600px centered.
  • Keyboard: Tab focuses search omnibox (/ hotkey). Active focus outline: 2px solid #6366F1 with 2px offset.
  • API Latency Edge Case: >3000ms triggers 56px height structural skeletons to prevent Cumulative Layout Shift (CLS).
SCR-02: AI Rebalance Drawer (Governor)
  • Motion Curve: 480px slide-over with easeOutCubic (240ms). Overridden to 0ms instant cut if prefers-reduced-motion is active.
  • Dynamic Interlock: Slider turns amber <15% buffer stock. If buffer hits 0, CTA changes to disabled with explanatory tooltip.
  • Undo Window: Approval triggers 60s reversible toast before transfer dispatch.
SCR-03: Pre-Flight CSV Modal
  • Form Feedback: Persistent top labels + permanent 16px helper-text container beneath inputs.
  • Plain-English Errors: Displays specific row failure: "Row 42: Negative quantity detected for SKU-9021" (Zero cryptic codes).
SCR-07: Warehouse Tablet Mode
  • Touch Standard: Actions enlarged to 54px full-width bounding box for industrial tablet carts.
  • WCAG 1.4.1 Signaling: Statuses pair color with distinct geometry (Hexagon, Triangle, Square).
