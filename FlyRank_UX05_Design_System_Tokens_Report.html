3. Eight Production-Ready Core Components

Component Variants & States Auto-Layout Specs Usage Rule (DO / DON'T)
1. Button Primary, Secondary, Destructive, Ghost | Large (48px), Med (40px), Sm (32px) | Default, Hover, Focused, Disabled, Loading Large: H:48px, Px:24px, Py:12px, Radius:8px. DO: Use Primary for final triage action. DON'T: Never place two Primary buttons together.
2. Form Input Text Input, Counter, Dropdown, Search | Default, Focused, Filled, Error, Disabled H:40px, Px:12px, Radius:6px, Border:1px. DO: Always show dedicated helper text. DON'T: Never use placeholders as labels.
3. Metric Card Inventory Health, Velocity, Wave Staging | Light, Dark | Static, Hover P:20px, Gap:12px, Radius:12px, Elevation-1. DO: Pair numbers with directional deltas. DON'T: Do not crowd >2 metrics per card.
4. Triage Modal Medium (640px), Large (880px), Drawer (480px) | Locked backdrop W:640px, P:24px, Radius:16px, Elevation-3. DO: Lock background scroll on open. DON'T: Never stack modals on modals.
5. Status Badge SYNCED (Hex), AT RISK (Tri), BLOCKED (Sqr), TRANSFER (Pill) H:24px, Px:8px, Radius:4px, Caption-Mono. DO: Pair color with unique geometry (WCAG). DON'T: Never rely on color alone.
6. Tactile Slider Continuous vs. Quick-Snaps (25%, 50%, Fill) | Desktop 24px vs Tablet 36px thumb Track H:8px, Active track colored, Snaps H:28px. DO: Show live real-time number counters. DON'T: Never allow reserve over-draw.
7. High-Density Row Standard, Alert, Selected, Expanded | Desktop 40px vs Tablet 54px touch Px:16px, Tabular nums, Border-b: 1px. DO: Right-align all numeric quantities. DON'T: Never truncate SKU codes.
8. XAI Math Drawer Collapsed Pill vs. Expanded Drawer | Live vs. Stale calculation P:16px, Radius:8px, Border: 1px dashed. DO: Render formula: (Velocity × Lead) + Buffer. DON'T: Never hide reorder math.
