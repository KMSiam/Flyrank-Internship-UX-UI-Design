2. COMPREHENSIVE STATE TRIADS (Loading, Empty, Error) FOR 3 CORE SCREENS:
   - Screen Triad 1 (SCR-01 Stock Grid):
     * Loading: 40px Shimmer Skeleton pulsing blocks with real-time sync microcopy.
     * Empty: "Zero Stockout Risks Detected" with illustrated checkmark and manual scan CTA.
     * Error: "TikTok Shop API Rate Limit (HTTP 429)" banner with exponential retry timer and last-known-safe stock fallback.
   - Screen Triad 2 (MOD-02 Rebalance Modal):
     * Loading: Tactile recalculation spinner disabling confirm action to prevent double mutation.
     * Empty: "Wholesale Reserve Pool Exhausted (0 Units)" with alternative FBA split suggestion.
     * Error: Concurrent edit conflict alert when another user alters stock in real-time.
   - Screen Triad 3 (MOD-03 Batch CSV Manifest Upload):
     * Loading: In-browser syntax tokenizer progress ring ("Linting Row 384 of 1,200...").
     * Empty: Dashed drag-and-drop zone with sample template download link.
     * Error: Dirty data warning highlighting trailing spaces in amber with 1-click "Auto-Sanitize & Strip Spaces".

4. CLAUDE 3.5 SONNET DESIGN CRITIQUE & AI-USAGE LOG:
