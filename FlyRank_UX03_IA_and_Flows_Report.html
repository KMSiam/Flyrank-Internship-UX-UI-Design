3. Three Annotated User Flows with Decision Points & Laws of UX

Flow 1: Primary Task — Emergency Multi-Channel Stockout Triage & Rebalance Elena (Founder)
Push Alert → Sync Health Amber? → Triage Board (SCR-04) → Wholesale Pool >= 150? → XAI Math Modal → Buffer Locked
Unhappy Paths Included:
• Sync Lag Alert: TikTok webhook latency >4m flags amber warning; force refresh executed in <400ms (Doherty Threshold).
• Insufficient Reserve: If wholesale reserve <50 units, system automatically calculates emergency split from Amazon FBA (Tesler's Law).
• API Rate Limit: Channel 429 response handled with optimistic UI update and exponential backoff (Error Prevention).
Interaction Law: Rebalance slider features 25%/50%/Max snap targets reducing decision time (Fitts's & Hick's Law); XAI exposes math formula (Jakob's Law).
Flow 2: Onboarding / First-Run — Zero-Friction Multi-Store Setup & SKU Auto-Mapping New Merchant
OAuth Connect → Token Valid? → Catalog Ingestion → 100% SKU Match? → 1-Click Alias Map → Launch
Unhappy Paths Included:
• Amazon SP-API Disconnect: Inline OAuth helper with developer key guidance eliminates setup dead-ends (Postel's Law / Robustness).
• SKU Syntax Mismatch: Flagging variant syntax differences (GLOW-01 vs GLOW_01) chunked into 5-card batches (Miller's Law).
Interaction Law: 15% default safety buffer pre-selected to eliminate decision fatigue (Default Effect); animated ingestion feedback preserves momentum (Peak-End Rule).
Flow 3: Recovery / Error Flow — Corrupted 3PL CSV Import Linter & Instant Undo Marcus (3PL Ops)
Drag CSV → Syntax & Headers Valid? → Linting Warning Drawer → 1-Click Auto-Clean → 60s Undo Clicked? → Floor Pick-Wave
Unhappy Paths Included:
• Missing Mandatory Column: Direct inline red warning with 1-click sample template download (Poka-Yoke / Mistake Proofing).
• Trailing Spaces / Formatting: In-browser linter highlights faulty rows with a 1-click "Auto-Sanitize & Strip Spaces" action (Postel's Law).
• Accidental Batch Overwrite: Persistent 60-second floating Undo Banner allows instantaneous state rollback without data loss (User Control & Freedom).
Interaction Law: Status badges rendered in 48px touch targets for warehouse tablets (Fitts's Law & WCAG Contrast).
