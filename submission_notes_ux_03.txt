2. COMPREHENSIVE INFORMATION ARCHITECTURE (IA) SITEMAP:
   - Grouping Logic: Task-Based and Object-Centric Hybrid Model designed to eliminate deep navigation nesting (the #1 friction point identified in Shopify/Katana teardowns).
   - 18 Screen Inventory organized into 5 primary functional domains + Persistent System Monitor:
     * Global Persistent Frame: Real-time Channel Sync Health Monitor (Shopify/TikTok/Amazon) & Stockout Alert Drawer.
     * 1.0 Inventory Matrix: Unified Multi-Channel Stock Grid, SKU Detail & Aliasing Drawer, Explainable AI (XAI) Math Inspector Modal.
     * 2.0 Triage & Rebalance Engine: Emergency Stockout Board, Cross-Channel Rebalancing Modal, Automated Buffer Rules.
     * 3.0 Orders & 3PL Warehouse Hub: Batch Manifests, Tablet-Optimized Floor Pick List (48px touch targets), Pre-Flight CSV Linting Modal.
     * 4.0 Demand Forecasting & Vendors: Predictive PO Generator, Supplier Blackout Calendar (Holiday shutdowns).
     * 5.0 Onboarding & First-Run Wizard: Store OAuth Stepper, SKU Auto-Match & Conflict Resolver, Baseline Calibration.

3. 3 ANNOTATED USER FLOWS (With Decision Points, Unhappy Paths & Laws of UX):
   - Flow 1 (Primary Task Flow): "Emergency Multi-Channel Stockout Triage & Rebalance"
     * Happy Path: Urgent push alert -> Live Sync Monitor check -> Triage Center -> 150-unit wholesale reserve rebalance -> XAI math verification -> Buffer locked.
     * Unhappy Paths: Sync latency delay warning (4m lag) with force refresh; Insufficient wholesale reserve pool (<50 units) triggering emergency split suggestion; API 429 rate limit with exponential retry.
     * Laws of UX Applied: Doherty Threshold (<400ms latency feedback), Tesler's Law (absorbing allocation complexity), Fitts's & Hick's Laws (slider snap targets), Jakob's Law (inspectable XAI math).
   - Flow 2 (Onboarding / First-Run): "Zero-Friction Multi-Store Setup & SKU Auto-Mapping"
     * Happy Path: Channel OAuth selection -> automated catalog ingestion progress -> 1-click SKU auto-alias mapping -> default 15% safety buffer activation.
     * Unhappy Paths: Amazon developer key OAuth drop with inline helper; Variant syntax mismatch (GLOW-01 vs GLOW_01) with inline visual difference resolver.
     * Laws of UX Applied: Postel's Law (Robustness Principle), Miller's Law (chunked 5-item SKU cards), Default Effect (pre-configured 15% safety buffer).
   - Flow 3 (Recovery / Error Flow): "Corrupted 3PL CSV Import Linter & Instant Undo Reallocation"
     * Happy Path: Drag-and-drop CSV -> Instant browser-side linting -> 1-click auto-sanitize -> dispatch to Marcus with STAGED status.
     * Unhappy Paths: Missing mandatory header (Tracking ID) with sample template download; Trailing spaces / dirty formatting flagged in amber with 1-click auto-clean; Accidental batch overwrite triggering 60-second floating Undo Banner for instant state rollback.
     * Laws of UX Applied: Poka-Yoke (Mistake-Proofing), Nielsen's User Control & Freedom (60s Undo), Peak-End Rule, WCAG 2.1 AA Contrast Ratios.
