2. The 3-Bullet Handover Note (Find Anything in 5 Seconds)

📌 Pinned Handover Architecture for Engineers & Product Managers
  • 1. Chronological Numbered Page Hierarchy (00 to 06): Sequenced from research to production code. Developers jump directly to 06_Developer Hand-off for pixel redlines and token CSS; PMs navigate to 02_IA & User Flows for product logic.
  • 2. Global Search via Strict Slash Syntax: Every component follows atomic hierarchy (Category / Component / Variant / Size / State). Press Shift + I and type Button / Primary or Badge / Status to locate any component variant in <2 seconds.
  • 3. Zero Ghost Layers & 100% Auto-Layout: All hidden scratch shapes and zero-opacity masks have been purged. Inspect elements in Figma Dev Mode with 0% visual guesswork—all margins, paddings, and responsive constraints are codified.
